# iPhone Duo 展开主框与外屏盖板

手机保持展开，一体主框连接两半。转轴位于盖口中脊侧，盖板向镜头侧翻开。左半背面结合用户3MF做屏幕开窗及始终连接的盖板，可向外打开180度，以一处中央机械卡扣闭合。展开内屏完全敞开，外背板和盖板保持平整，侧面保留四道居中浅纹；内侧恢复参考MagSafe圆环及定位尾槽，其余磁吸卡扣及装饰图案取消。

主框基础168.3×121.5、内腔165.01×118.21、主背板参考主体2.5（外侧减薄0.9），内侧一体补0.2后普通总厚2.7、支承面Z2.6，沿用164.6×117.8×5.2机身试配。顶部开口X[-104.5,24]、两端余边19.9；底部X[-107.4,26.9]、两端余边17，保留既有电源和拍照通道。左直段Y±47.15取消连续内收扣边，中央Y±8增加短内收卡扣，长16、内收0.7、厚0.7，边缘R0.15、距屏面0.38；其余释放区域、围墙和圆角保留。侧面四道环绕浅纹深0.15、高0.6、节距1.2，以完整侧厚Z[-0.1,8.88]为基准居中，槽中心Z2.59/3.79/4.99/6.19，上下留白各2.39；四条浅纹连续通过外侧短边，与两端保持同高对齐。

左侧净窗75.8×113.6，盖板76.9×114.7×1.6，外面Z-0.1与主背板平齐，边隙0.25、止挡间隙0.1，中脊侧两角90度。中脊侧采用上中下三组独立窄铰链，中心Y=-45/0/45，轴心X-41.1/Z-3.85不变。每组宽10，两固定耳各2.5、中间活动耳4、两处轴向间隙各0.5；外径5.2、孔Ø2.8保持。三根Ø2.2×11无帽短销各配一组，径向间隙0.3，每根在一固定耳少量点胶，活动耳不涂胶。六个固定轴耳改为独立侧滑件，从图示屏幕缺口横向推入六个敞口浅槽后胶粘。槽深按默认0.8、底厚1.9、净宽2.66，轴耳脚3.9×2.5，两侧、止端及槽底各留0.08装配间隙，轴孔位置不变，胶由用户自行选择并实施；盖板端45度实心斜接、根部伸入4.9及颈部2.2保持，不设悬空或外露方块，外框不开穿轴凹槽。翻盖版三处边缘凹槽同步封闭版：入口29/22/22、内退1/1.7/1.7，六端R2大圆弧平顺相切。

盖板完全翻平后覆盖镜头区域，与镜头圈间隔约4.1；拍照时需要合盖或将盖板抬离镜头方向。

镜头圈保留既有外向加高0.8，圈尺寸不变并随安装面内移0.9，保护顶Z-3.5、胶面Z-0.25、内定位顶Z0.15。用户选择镜头圈不再加高，接受紧凑轴体高于镜头圈2.95。

外侧仅保留一组Y0居中卡扣，与凹槽位置对齐；旧上下卡扣、拨点和配合槽取消。舌片长16/宽2、隔离槽1，扣钩长7.5/高0.8、Z0.7–1.5，实扣0.5、释放0.8；固定承力肩0.8，内侧腔顶封闭0.6、净空0.3。仅一处贴盖口内边的居中7.9×1.6/R0.5窄凹槽（与外露卡扣等长），默认深0.3、跨入盖口0.05；原外侧槽填实，接收腔下方净承力厚0.5，实际保持力需试样验证。先内推中央拨点，再抬起盖板。

翻盖版取消独立内贴片，其0.2厚度补为主框内侧一体材料，包含原Z2.4平面支承区和屏窗止挡上侧；屏幕开窗、镜头开孔、磁环及尾磁槽不封盖。手机落座面仍Z2.6，围墙6.48、扣边及屏幕侧0.38间隙保持，盖板位置不动。

外背板及盖板不设装饰胶囊凹槽，名义厚度分别为主背板2.7、盖板1.6，两者主体外表面共面Z-0.1。

MagSafe按上传STEP的位置与形状开在镜头半侧内底：圆环内径45、外径54.72，中心(2.05,-2.41)；尾槽16.98×6.99、R3.495，中心(2.05,-40.16)，环尾间隔1.9。按用户指定，从内侧开槽，槽底至背板外面的剩余厚度为1.15：当前普通背板2.7，槽深1.55、槽底Z1.05，外背面Z-0.1保持平整。仅建立安装槽，实际磁体与胶层需匹配槽尺寸及深度；磁体装配尺寸需试配确认，无线充电对中和磁吸力未经验证。

红色主框默认TPU95A，盖板、六个固定轴耳、直销和镜头圈默认PETG，不再需要独立内保护贴片。翻盖版为主框、盖板、六个独立固定轴耳、三根短销、镜头圈，共十二件试配装配；检查完整外框、短销插入、解扣后的180度运动及一体内侧补偿的净空。实机屏面、卡扣力、销轴保持力和寿命需样件验证。

## 封闭对照版本
额外保留无翻盖封闭版，放在原版右侧X+195。外廓168.3×121.5，左右短内壁各向内加厚0.055，内腔164.9×118.21，外形不缩短；卡边随内壁同步，左右镜像匹配。内侧屏区盲凹78×115.81，三边留1.2，右边X-43.5，凹底Z1.5、主体底厚1.6；接口槽局部底厚1.5。取消独立贴片，0.2厚度与壳体内侧一体，含左侧支承带，支承面Z2.6、相对凹深1.1。镜头孔与磁槽保持开放，磁槽底厚1.15、深1.55。
上边凹位总入口长29、内退1；右侧两处凹位总入口各22，按Y16.1/-27居中，至内壁台阶X42.2、内退1.7。三处凹槽的六端统一改成大圆角的平顺过渡，按默认R2双反向相切圆弧，入口总长度包含两端过渡，中央直段相应缩短。镜头旁上槽不再加深。仅两件：封闭主壳与镜头圈，四道侧纹、20度斜切及底边接口保持。

## 两版本底边接口
两个版本的下长边与上边同为20度外低内高斜切，沿用R1端角、R0.3外沿。左半手机中轴X-81.4处新增宽12.7、从底边Y-60.75向内延伸3.4至Y-57.35的开顶接口凹槽，槽底Z1.4、距外背面Z-0.1约1.5，内端默认R0.3。3.4为向内距离；槽区局部底厚1.5，其余屏区厚度保持。翻盖版接口内侧跨槽的细止挡条切除，12.7宽槽口向屏幕开窗敞开，其余止挡保留。实机接口和线缆外壳需试配。
