# iPhone Duo 展开主框与外屏盖板

手机保持展开，一体主框连接两半。左半背面结合用户3MF做屏幕开窗及始终连接的盖板，可向外打开180度，以两处机械卡扣闭合。展开内屏完全敞开，外背板和盖板保持平整，侧面保留四道居中浅纹；取消磁吸及其他装饰图案。

主框基础168.3×121.5、内腔165.01×118.21、板厚3.4，沿用164.6×117.8×5.2机身试配。顶部开口X[-104.5,24]、两端余边19.9；底部X[-107.4,26.9]、两端余边17，保留既有电源和拍照通道。左直段Y±47.15取消内收扣边，保留围墙和圆角。侧面四道环绕浅纹深0.15、高0.6、节距1.2，以完整侧厚Z[-1,8.88]为基准居中，槽中心Z2.14/3.34/4.54/5.74，上下留白各2.84；转轴连接区Y±35.333333内截断，保留承力材料。

左侧净窗75.8×113.6、R10.5，中心(-81.4,0)；盖板76.9×114.7×2.5，边隙0.25、止挡间隙0.1。转轴有效跨度66.67，沿Y居中，轴节外径5.2、轴心X-121.7/Z-3.85，最外X-124.3收在壳体侧边X-124.4内。固定三轴耳外侧为直立边与R2.6圆弧顶相切、底座与壳体连实；盖板端保留45度外斜面，下方填实为三角支撑直接连到盖板，取消悬空和外露方块；原外框不开穿轴凹槽。Ø2.2×67.67无帽直销保留，中耳Ø2.05轻压定位，其他孔Ø2.8，两端导入口0.5。

镜头圈保留既有外向加高0.8，保护顶Z-4.4、胶面Z-1.15、内定位顶Z-0.75。用户选择镜头圈不再加高，接受紧凑轴体高于镜头圈2.05。

两处盖板卡扣臂16×2、板厚2.5、隔离槽1，扣钩接触长5、高1.1，实际扣量0.5、向内释放0.8。外侧拨点高0.6；先内推解扣，再由16×8、深1.4的指槽抬起盖板。

内底增加深灰TPU保护薄片，含胶总厚0.2，距内壁0.2；屏幕盖口外让0.4、镜头内开口外让0.5，不覆盖屏幕或摄像头。手机落座面从Z2.4升至Z2.6，围墙高6.48、扣边同步抬高0.2，屏幕侧原0.38间隙保持。

外背板及盖板取消全部胶囊凹槽，名义厚度分别为3.4和2.5。

红色主框默认TPU95A，盖板、直销和镜头圈默认PETG，贴片由0.2总厚柔性薄膜裁切。交付五件参数化STEP试配装配；检查完整外框、双向穿轴、解扣后的180度运动及贴片净空。实机屏面、卡扣力、销轴保持力和寿命需样件验证。
