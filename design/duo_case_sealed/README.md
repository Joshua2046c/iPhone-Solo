# iPhone Duo 无翻盖封闭版本

## Design intent
封闭版与原翻盖版并排，X偏移195 mm。外背板平整连续，没有翻盖、轴耳、销、斜臂、翻盖卡扣、接收槽或指槽。手机固定内收边保留，左侧短扣按右侧中央卡边作精确镜像，内收量0.7、厚0.7，两端过渡一致。
红色主壳与银白镜头圈两件装配；取消独立内贴片，将其0.2厚度直接补偿为主壳内侧连续材料。左侧支承窄边和屏区周围也补齐，唯屏幕下凹区域不增加材料；原翻盖版不修改。

## Interfaces and defaults
- sealed_display_inner_recess：盲凹78×115.81、中心X-82.5/Y0，左两角R10.755、中脊两直角；左/上/下距内壁各1.2。右凹边X-43.5不变。凹底Z1.5、外面Z-0.1、连续底厚1.6不变；周围支承面由Z2.4升至Z2.6，相对凹深1.1。
- sealed_integral_inner_compensation：原0.2贴片厚度整合进主壳内侧所有Z2.4平面支承区，补至Z2.6并与本体连实；包括左侧和三边支承带。屏区凹底、镜头孔、磁环与尾槽不覆盖。没有独立inner_liner零件或贴片裁切轮廓。
- sealed_left_retention_match：镜像右中央卡边至左侧，镜像面X-40.25；两侧名义区间Y[-14.5,2.7]、中心Y-5.9、跨度17.2，按右侧端部R1截面及现有沿边处理；Z8.18–8.88，内收0.7、根部进入围墙0.4。原左侧16长/Y0独立圆角条取消。
- sealed_phone_fit：164.6×117.8×5.2展开机身，原内腔164.9×118.21、支承面Z2.6、屏幕侧扣边间隙0.38保持。围边/手机卡边位置不再升高，补偿只替换原贴片所占厚度。
- sealed_continuous_back：外廓168.3×121.5，外面Z-0.1；原主背板2.5加内侧0.2补偿，普通支承区总厚2.7。屏区底厚1.6。
- sealed_grip_ports：四道居中浅纹深0.15/高0.6/节距1.2及原接口保持；斜坡、镜头弧面和非平面开口不填覆。
- camera_guard_bond：净孔56.3×20.5、外翼3.25、总高3.65、定位环0.4、胶层0.15；位置[10,43.9,-0.25]、保护顶Z-3.5保持。
- sealed_magsafe_seats：内径45/外径54.72、中心(2.05,-2.41)，尾槽16.98×6.99。槽底Z1.05、距外面余厚1.15；开口支承面升到Z2.6后可用深度1.55。磁槽保持内侧开放，不封盖，不建立磁体替身。参考用户STEP SHA256 163db2c6683f456fee5702e453d44d076a87c3b8f131c5095fbb0bc44ed767d9。

## Making and assembly
两件：TPU95A封闭主壳及PETG镜头圈；无独立贴片，无盖板或连接销。
建议主壳平整外背面朝平台试切片，磁环槽和屏区盲凹朝上，0.2层高。补偿与主壳一体打印，不另外贴膜或叠加胶层；屏区底厚1.6、磁槽底厚1.15及支承窄边检查连续实心填充。内收扣边和接口根据实际切片选择局部支撑，功能面避免支撑损伤，实机装配前先做局部试样。
镜头圈用0.15胶层粘接；磁环/尾磁铁从内侧装入并可靠粘接，槽内总高度须不超过1.55、表面不高于Z2.6支承面。不再有薄膜覆盖磁体，固定及表面处理不得留下接触手机的尖边，具体磁体、胶种和保持力须样件验证；无线充电与吸附未经实测。手机按原柔性围边逐段装入并保持展开，不可用屏面或手机铰链作撬动支点。外屏由背板封闭，无法从背面直接操作。

## Lower edge access
图示下长边开口与上边同为外低内高20度斜切，沿用R1端角及R0.3外沿过渡。左半手机区域中轴X-81.4，下边Y-60.75处新增开顶接口缺口：X向宽12.7，自外边向内延伸3.4至Y-57.35，槽底Z1.4，至外背面Z-0.1保留1.5；默认两内端平面角R0.3。3.4为向内距离，不是竖向高度。新增槽与原底部长开口连通。

接口缺口处局部底厚1.5优先于原屏区连续底厚1.6；其他屏区凹底及厚度保持。实机接口和线缆外壳试配尚未完成。

## Edge recesses
封闭版上方29 mm、右侧两处各22 mm的凹位，六个端部统一改为双相切大圆弧过渡，默认圆弧R2 mm。每端由两段反向相切圆弧将原外边平顺接至凹槽底边，没有短直立台阶。
总入口范围保持上方X[-5,24]、右侧Y[5.1,27.1]和[-38,-16]。上方内退1，右侧内退1.7至内壁台阶X42.2；大圆弧占入口长度内的端部空间，中间直段相应缩短。镜头孔、磁槽及两侧中央卡边不变。

## Short-edge inner fit
仅封闭版左右两条短边内侧各向内加厚0.055，外围168.3×121.5保持。内腔沿X由165.01减为164.9，名义手机总间隙由0.41减为0.3，两端各0.15；Y向118.21不变。两侧卡边和圆角沿新内壁同步，左右镜像匹配保持；屏区左边随内壁向右0.055，右边X-43.5不动，1.2留边保持，盲凹变78×115.81。
用户澄清只加厚内腔：两端各0.055、合计0.11，外廓长度不缩短。

## Validation
已放大核验三个凹槽六端的大圆弧平顺连接。三个切割轮廓均为一个有效闭合轮廓，十二段圆弧半径均为2 mm。主壳和镜头圈各为一个有效实体；对比修改前仅主壳改变，外廓包围盒不变。外廓168.3×121.5、内腔164.9×118.21，上槽内退1、侧槽内退1.7保持。上槽至镜头扩孔的最小余量0.59506 mm，连续余量保留；实机配合及薄边强度待局部试样验证。
