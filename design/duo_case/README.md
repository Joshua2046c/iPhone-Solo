# iPhone Duo 展开主框与外屏翻盖

## Design intent
手机仍保持展开，主框仍是一体件。左半背面按用户3MF的屏幕镂空形式开窗，并安装始终连接的独立屏幕盖板；盖板可向壳外打开180°，闭合用两处弹性卡扣固定。内屏侧完全开放。
外观为红色圆角主框与同色平整盖板，外背板及盖板取消胶囊凹槽，保留摄像头圈和侧面四道居中浅横纹。

## Reference
参考附件20261106T211009745Z-1-iphone-duo-case-pipes.3mf为毫米单位的网格装配，已读取各部件和切片。主体参考外包络约170.535×123.535，左窗截面宽约75.7868、高约114.6736；参考含TPU/PLA装配及侧边环绕细槽。当前主框仍沿用用户展开机身164.6×117.8×5.2及现有168.3×121.5名义外廓；只借用开窗布局与纹路，不整体缩放该网格。

- permanent_frame：主框跨两半仍为一个连续实体，左侧开窗不将主框分成两个壳。
- display_lid：默认净窗75.8×113.6、R10.5，中心X-81.4/Y0；背面盖口77.4×115.2、R11.3，盖板76.9×114.7×2.5，边隙0.25。闭合外面Z-1齐平，内面Z1.5，距含贴片手机落座面1.1；止挡厚0.8，盖内面到止挡0.1。

## Making and assembly
主框默认TPU95A，盖板和定制直销PETG，镜头圈PETG；铰链与卡扣均为自由实现，不使用螺钉或采购铰链。主框和盖板分件打印，对齐交错轴耳后由任一端穿入等径直销，中固定耳为0.15直径过盈的轻压配合，用于定位直销、保持连接；活动盖板孔仍为径向0.3活动配合。连接销不涂胶，也没有端帽；镜头圈用原0.15外翼胶层固定。
紧凑轴耳和斜连接臂需要检查局部支撑，不能直接按旧版外背面贴平台的姿态摆放。盖板可优先以内面朝平台试切片，45度斜臂和轴孔按实际悬垂情况安排局部支撑；主框按实际切片选择侧立或倾斜姿态，卡扣根部与横孔需按实际切片支撑，优先做短轴和卡扣试样再整件。主框背面开窗后仍需完整中脊支承；不要用手机铰链或屏面作撬动支点。主体柔性围边按原低力逐段试装，手机保持展开。
贴片建议由0.2总厚柔性薄膜裁切，胶层包含在0.2内，不另叠加；贴在内底平面后再安装手机。
建议打印样件0.2层高，支撑不得伤及镜头配合面及盖板舌片。实机屏幕边框、屏面高度、卡扣释放力、销轴保持力和寿命仍须试样；附件网格不是实机机械图。

## Table support and access
用户保留镜头圈现有高度并接受轴体更高。镜头圈保护顶Z-4.4，紧凑轴体最外Z-6.45；无共面平放要求，已取消的两额外凸脚不恢复。
主框基础168.3×121.5，含轴闭合总宽168.3。抠盖指槽16×8、深1.4，槽下余厚2.0；四道侧纹深0.15、节距1.2及圆滑过渡R0.075保持。按原方式先向内推回两卡扣拨点，再从指槽抬起盖板。

## Assembly pose and pin ends
闭合盖板位置[0,0,0]、无旋转；180度打开位置[-243.4,0,-7.7]、旋转[0,180,0]。直销位置[-121.7,0,-3.85]。
五节轴耳端部Y±33.333333，中固定耳Y±6.666667；两活动耳Y[-22.166667,-7.166667]及[7.166667,22.166667]。直销Ø2.2、长67.666667，两端Y±33.833333，各外露0.5；端面仅0.1导入倒角，无凸头和盖帽。Ø2.05中固定孔与直销径向过盈0.075、直径过盈0.15，在直销源中声明为press_fit。四件打印件：主框、盖板、直销、镜头圈，另加一片0.2总厚的内保护贴片。

## Validation
五件均为单个有效实体。活动连接下方两处实料探针（X-118.8、Z-1.4，宽0.5、高0.8）体积各5.76 mm³，与盖板交集均等于完整探针体积，原三角空隙处已填实。固定三轴耳外侧平面X-124.3、法线[-1,0,0]，从轴心Z-3.85直立至背板圆边附近，与R2.6圆弧顶相切；局部连接倒圆R0.3。盖板斜面仍45度，支撑为实心楔形，根部在盖板厚度内，不设置外露方块。
将原壳体平面轮廓沿高度拉伸为包络，主框、盖板和通条位于包络外的体积均为0；含轴闭合外宽168.3，侧边留0.1。轴心X-121.7/Z-3.85、孔径和通条尺寸保持。
解扣后采用保守盖板包络，0–0.95度每0.05度、1–180度每1度共200角度采样，盖板对主框交叠均为0。双向插轴路径从装配位置沿Y移动110再反向220，661姿态、步长0.5、网格弦差0.02；共享区域仅在中固定耳Y±6.276内，6.197 mm³、深0.0771，为预期轻压定位，活动孔最小间隙约0.2992。
构建报告唯一直销与中固定耳声明的0.15直径压配：精确共享6.225851 mm³、最大0.083深度，在预算内；没有其他未声明干涉。
平整外背面、四条居中侧纹、0.2内贴片、镜头圈与加固卡扣的接口保持。打印尺寸、插入力、销轴保持力及卡扣手感和寿命需试样；不宣称背面共面平放。
