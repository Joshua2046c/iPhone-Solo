# iPhone Duo 展开主框与外屏翻盖

## Design intent
手机仍保持展开，主框仍是一体件。左半背面按用户3MF的屏幕镂空形式开窗，并安装始终连接的独立屏幕盖板；盖板可向壳外打开180°，闭合用外侧中央一组弹性卡扣固定。内屏侧完全开放。
外观为红色圆角主框与同色平整盖板，外背板及盖板取消胶囊凹槽，保留摄像头圈和侧面四道居中浅横纹。

## Reference
参考附件20261106T211009745Z-1-iphone-duo-case-pipes.3mf为毫米单位的网格装配，已读取各部件和切片。主体参考外包络约170.535×123.535，左窗截面宽约75.7868、高约114.6736；参考含TPU/PLA装配及侧边环绕细槽。当前主框仍沿用用户展开机身164.6×117.8×5.2及现有168.3×121.5名义外廓；只借用开窗布局与纹路，不整体缩放该网格。

## Making and assembly
主框默认TPU95A，盖板和三根定制短销PETG，镜头圈PETG；铰链与卡扣均为自由实现，不使用螺钉或采购铰链。主框和盖板分件打印，每组三节轴耳对齐后从任一端穿入一根Ø2.2×11无帽短销，九节轴耳均Ø2.8直孔，径向间隙0.3。每根销在其一侧固定耳少量点胶，活动耳不涂胶；避免胶流入0.5轴向间隙。胶须适配TPU/PETG并可填0.3间隙，胶种及保持力需样件验证；完全固化后再翻动。镜头圈用0.15外翼胶层固定。
紧凑轴耳和斜连接臂需要检查局部支撑，不能直接按旧版外背面贴平台的姿态摆放。1.6厚盖板可优先以内面朝平台试切片，45度斜臂和轴孔按实际悬垂情况安排局部支撑；主框按实际切片选择侧立或倾斜姿态，卡扣根部与横孔需按实际切片支撑，优先做短轴和卡扣试样再整件。主框背面开窗后仍需完整中脊支承；不要用手机铰链或屏面作撬动支点。主体柔性围边按原低力逐段试装，手机保持展开。
先将匹配磁环/尾磁铁装入内侧槽并固定，再覆盖保护贴片；磁体和胶层合计须不高于内底支承面，1.35为可用槽深。磁环与胶层总厚应匹配1.35槽深，装配保持力仍需样件确认。
贴片建议由0.2总厚柔性薄膜裁切，胶层包含在0.2内，不另叠加；贴在内底平面后再安装手机。
建议打印样件0.2层高，支撑不得伤及镜头配合面及盖板舌片。实机屏幕边框、屏面高度、卡扣释放力、销轴保持力和寿命仍须试样；附件网格不是实机机械图。

## Table support and access
用户保留镜头圈现有高度并接受轴体更高。镜头圈保护顶Z-3.5，紧凑轴体最外Z-6.45；无共面平放要求，已取消的两额外凸脚不恢复。
主框基础168.3×121.5，含轴闭合总宽168.3。盖板向镜头侧翻开，180度时位于该半背板上方，需核验镜头圈净空；盖板实体会遮挡镜头视线，拍照时需合上盖板或将其抬离镜头方向。贴盖口内边的单个7.9×1.6/R0.5居中指槽、深0.3，接收腔下方净厚0.5；四道侧纹深0.15、节距1.2及圆滑过渡R0.075保持。先向内推回中央卡扣拨点，再从指槽抬起盖板。

## Assembly pose and pin ends
闭合盖板位置[0,0,0]、无旋转；180度打开位置[-82.2,0,-7.7]、旋转[0,-180,0]。三根短销分别位于[-41.1,-45,-3.85]、[-41.1,0,-3.85]、[-41.1,45,-3.85]，销Ø2.2、长11、端面0.1导入倒角。三组沿Y整体区间[-50,-40]、[-5,5]、[40,50]。每组活动耳长4，固定耳各2.5，两处间隙0.5。
六件打印件：主框、盖板、三根短销、镜头圈，另加一片0.2内保护贴片。

## Edge recesses
三处边缘凹槽与封闭版本同步：上槽总长29、内退1，侧面两槽各22、内退1.7。总入口X[-5,24]、Y[5.1,27.1]及[-38,-16]，六端均采用R2反向相切大圆弧，外边与槽底平顺连接，中央直段相应缩短。原内腔和其余卡扣保持。
