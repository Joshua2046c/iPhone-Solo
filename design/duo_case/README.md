# iPhone Duo 展开主框与外屏翻盖

## Design intent
手机仍保持展开，主框仍是一体件。左半背面按用户3MF的屏幕镂空形式开窗，并安装始终连接的独立屏幕盖板；盖板可向壳外打开180°，闭合用外侧中央一组弹性卡扣固定。内屏侧完全开放。
外观为红色圆角主框与同色平整盖板，外背板及盖板取消胶囊凹槽，保留摄像头圈和侧面四道居中浅横纹。

## Making and assembly
主框默认TPU95A，盖板、六个独立固定轴耳、三根短销及镜头圈默认PETG；铰链和胶粘安装位均为自由实现，不使用螺钉或采购铰链。先不安装盖板、短销及手机，将六轴耳从屏幕缺口侧沿横向推入对应的敞口浅槽；入槽脚落在槽底胶层上，不从背面垂直压入。先干配并用盖板和三根短销校准共轴及0.5轴向间隙，再按胶工艺固定、保持0.08胶层并固化，避免胶进入活动耳或孔内。三根Ø2.2×11无帽短销分别配三组Ø2.8轴孔，径向间隙0.3，每根可在一侧固定耳少量点胶防滑出。胶由用户自行选择，材料相容性和保持力须样件验证。镜头圈仍用0.15外翼胶层固定。
主框取消一体固定轴耳，可优先以外背面朝平台试切片，注意0.8深敞口滑槽的形状。六个独立轴耳可优先以平整入槽脚底面朝平台试切片，保护胶接面及2.5宽滑脚；Ø2.8横孔按实际切片安排局部支撑。盖板原45度斜臂和轴孔按实际悬垂安排支撑，不伤及功能面。不要以手机屏面或手机铰链作撬动支点。
匹配磁环和尾磁铁从内侧装入开放槽并可靠固定，磁体及胶层合计不高于Z2.6支承面，当前可用槽深1.55。取消覆盖贴片，固定及表面处理不得留下接触手机的尖边；胶种、磁体与保持力须样件验证。
内侧0.2补偿与主框一体打印，不另贴膜或叠胶。原磁环槽、尾槽、镜头孔及屏幕开窗不填覆。
建议打印样件0.2层高，支撑不得伤及镜头配合面及盖板舌片。实机屏幕边框、屏面高度、卡扣释放力、销轴保持力和寿命仍须试样；附件网格不是实机机械图。

## Table support and access
用户保留镜头圈现有高度并接受轴体更高。镜头圈保护顶Z-3.5，紧凑轴体最外Z-6.45；无共面平放要求，已取消的两额外凸脚不恢复。
主框基础168.3×121.5，含轴闭合总宽168.3。盖板向镜头侧翻开，180度时位于该半背板上方，需核验镜头圈净空；盖板实体会遮挡镜头视线，拍照时需合上盖板或将其抬离镜头方向。贴盖口内边的单个7.9×1.6/R0.5居中指槽、深0.3，接收腔下方净厚0.5；四道侧纹深0.15、节距1.2及圆滑过渡R0.075保持。先向内推回中央卡扣拨点，再从指槽抬起盖板。

## Side-slide ear installation
1. 先不装盖板、销或手机，清洁六个侧开滑槽及入槽脚。
2. 每个固定耳从图示屏幕缺口侧沿横向滑向背板，进入对应的敞口槽；远端槽壁限位，两侧各0.08留量，不作压配。
3. 干配六耳后穿入三根短销并用盖板校准共轴，维持0.5轴向间隙；按胶工艺控制0.08胶层并固化，不粘死活动耳。
4. 固化后核验短销和开合，再装磁体及手机。槽底不穿透，胶接保持力须试样验证。
